## About Electron Executor

Electron Executor is a Windows application for Roblox users who need a compact environment for Lua injection and script execution. Its straightforward desktop layout includes a script hub, allowing scripts to be discovered and launched from one place instead of relying on multiple separate utilities.

Build 3.2 emphasizes efficient day-to-day use with one-click launches, batch operations, and a queue that remains available between sessions. The application also provides automatic updates and a multi-language interface for current Windows systems.
